# Embed texts

Embed texts

## Usage

``` r
embedTexts(model, texts)
```

## Arguments

- model:

  A
  [`visionModel()`](https://leipzig.github.io/dimoose/reference/visionModel.md).

- texts:

  Character vector, without missing values.

## Value

A `texts x d` matrix with the texts as row names (no rows for no texts).
