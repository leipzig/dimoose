Make a key from a spreadsheet

Write a dichotomous key in Excel or Google Sheets, save it as CSV, and turn it here into an interactive page that works offline on a phone. There is nothing to install: this page runs dimoose in your browser, and your files never leave your computer.

    How to write the spreadsheet

    One row for each lead (each choice). The two or more leads of a couplet share its number. Download the Montana spreadsheet to use as a template.

    CoupletQuestionDescriptionGoes toSpeciesPhoto
    1Leaf type?Leaves compound, divided into leaflets.2ash_leaf.jpg
    1Leaf type?Leaves simple, a single blade.3
    2Leaflets?3 leaflets with a few coarse teeth.Box elder (Acer negundo)boxelder
    2Leaflets?5 to 7 leaflets with toothed margins.Green ash (Fraxinus pennsylvanica)

    Couplet and Description are required. Each row needs either Goes to (the couplet it leads to) or Species (the result), not both. Question and Photo are optional; several photos are separated by semicolons and the file extension may be left out. If a description contains a comma, the spreadsheet program puts it in quotes for you when it saves the CSV.

    Problems in the sheet are reported by row number, so you can fix the row and try again.

    Made with dimoose running on webR. The first visit downloads R, which can take a little while; after that the browser keeps it. R users get more: keyFromSpreadsheet(), keyDiagram() and name checking against GBIF.
